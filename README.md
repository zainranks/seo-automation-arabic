# SEO Automation بالعربي

سكريبتات وسكيلز مجانية من سلسلة **SEO Automation من الصفر** لـ [خالد زين](https://www.facebook.com/ZainRanks).

كل حلقة بتاخد مهمة سيو بتتكرر في الشغل، وبتحولها لأداة شغالة تاخدها وتستخدمها على طول، حتى لو مابتعرفش تكتب كود. بنبدأ بـ Google Apps Script من غير أي تسطيب، وبعدين Python والـ APIs، وفي الآخر Claude Code Skills.

## إزاي تستخدم أي أداة

- **أدوات Google Apps Script:** افتح لينك "Make a copy" اللي في صفحة الحلقة، أو انسخ ملف `Code.gs` في شيتك من Extensions > Apps Script.
- **أدوات Python:** الخطوات في صفحة كل حلقة.
- **Claude Code Skills:** الخطوات في صفحة الحلقة 11.

## قواعد السلسلة

- مفاتيح الـ API عمرها ما تتحط في الكود أو جوه خلية في الشيت. بنحطها في Script Properties أو ملف `.env`.
- الأداة بتساعدك تاخد قرار سيو، مش بتاخده بدالك. اختبر أي أداة على لينكات إنت عارف نتيجتها قبل ما تثق فيها.
- بنستخدم APIs رسمية بدل ما نحاول نتخطى حماية المواقع.
